# Docs

`tracker-snapshot.html` is a point-in-time copy of the interactive build
tracker (published as a Claude artifact - the browser localStorage version
there is the live, editable one). This file is a git-tracked backup: open
it in a browser to see the state as of its last commit, or re-publish it
as an artifact if the live link's browser data is ever lost. It won't
reflect live edits until manually re-exported and copied here.
